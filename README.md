# Frederico Foini — Portfolio

Personal portfolio for Frederico Foini, focused on Data Analytics, Growth, and Product. The site presents selected business outcomes, career history, current projects, skills, education, and contact links.

## Prerequisites

- Node.js `>=22.13.0`

## Local development

```bash
pnpm install
pnpm run dev
pnpm run build:pages
```

The production build is statically exported with the `/website` base path and deployed to GitHub Pages through the repository workflow.

## Quality checks

```bash
pnpm run lint
pnpm run build:pages
```
